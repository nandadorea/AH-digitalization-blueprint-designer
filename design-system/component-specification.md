## Capability Resource

A Capability Resource is any reusable knowledge asset that supports the implementation of a Building Block.

Capability Resources are the fundamental contents of the Blueprint Knowledge Library. A Blueprint does not contain the resources themselves; it organizes and references them.

Each Capability Resource should have:

- Name
- Purpose
- Resource Type
- Library Status
- Description
- Source (if existing)
- Notes

### Resource Types

Capability Resources may take different forms depending on the knowledge they provide.

Current resource types are:

| Type | Purpose |
|------|---------|
| Guidance | Explains concepts, principles and recommended approaches. |
| Template | Provides a reusable structure for countries to complete or adapt. |
| Worked Example | Demonstrates what a completed resource might look like. |
| Reference Artefact | A reusable implementation asset such as a data dictionary, standard, ontology, code list or reference model. |

Future resource types may be added as the Blueprint Designer evolves.
